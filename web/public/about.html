TECHNICAL NOTES / 01

What happens between
the pixel and the answer.

This project trains a small neural network with NumPy, exports its parameters as JSON, and reproduces the forward pass in the browser with plain JavaScript.

Forward pass

The browser receives the normalized 28 × 28 drawing, flattens it to 784 values, and applies the same operations as the Python model:

784input pixels
ReLU128 hidden values
softmax10 probabilities
argmaxpredicted digit

Training

  • MNIST handwritten digit dataset
  • Mini-batch gradient descent
  • He initialization
  • ReLU hidden layer
  • Softmax cross-entropy output

Input alignment

Canvas ink is converted to a 28 × 28 intensity array. The frontend finds the ink bounding box, scales it into the MNIST writing area, then shifts the result using its center of mass before inference.

Deployment

The site is static. weights.json is fetched by the browser, and inference runs in inference.js. No Flask, Node server, TensorFlow.js, or ONNX runtime is involved.

Weight export

model/main.py serializes W₁, b₁, W₂, b₂ into JSON and mirrors the file into web/public/ for the Vite build.
